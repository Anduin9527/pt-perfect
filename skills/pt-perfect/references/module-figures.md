# 模块图（网络结构展开图）

模块图回答“这个网络里面是什么”。它与框架图的区别在于：框架图讲一条数据流和一个论点，模块图讲层级——整体由哪些块组成，每个块内部又是什么。读者拿着它对照代码或复现，因此完整和准确优先于简洁。

本文件的规则来自对一张已发表模块图（3DSMT, Fig. 2）的拆解与复刻，以及据此绘制的若干模块图；`assets/examples/vit-module.tsx` 是一张小型范例（Vision Transformer 逐层展开）。

## 结构：三层，逐层展开

| 层 | 内容 | 画法 |
| --- | --- | --- |
| 总览 | 输入到输出的完整网络，每个阶段是一个块 | 横向一行，占满宽度 |
| 阶段 | 一个阶段内部的层序列、残差旁路、跳连的取出与接入 | 纵向窄列，放在两侧 |
| 算子 | 论文贡献所在的块，展开到单个算子 | 横向宽面板，放在中间 |

每一层只展开一次。总览中重复出现的阶段（四个编码级）在阶段层只画一个带下标的代表（$E_i$），各级之间的差异（通道数、分辨率、末级不下采样）放回总览用表格或图形编码表达。

展开到哪一层为止：标准层（Conv、GN、SiLU）到此为止；论文提出或改动的块展开到公式中的每一项；沿用他人的块，只在读者需要它来理解接口时才展开。

## 从代码出发

模块图的每个框和每条线都对应代码中的一行。动笔前把 `forward` 逐行列成清单：层的顺序、每处通道数、分支在哪里取出和汇合、残差加在哪里、条件（时间、类别）从哪里进入。正文的文字描述会省略细节（跳连取出的位置、堆栈弹出的顺序、末级的特例），以代码为准；两者不一致时告知作者。

画完后反向核对一遍：指着图上每个元素说出它对应哪一行代码，再指着代码每一行找到它在图上的位置。

## 版面

- **窄列放两侧，宽面板放中间。** 阶段列是纵向的窄条，算子面板是横向的宽条。把被展开的块所在的列放在紧邻其面板的一侧，放大引线才不会跨过别的内容。
- **列内流向与面板顺序一致。** 列自上而下，则上方的块对应上方的面板。两条引线不应交叉。
- **面板内部先数行。** 把算子图的分支排成水平的行（例如 q、k、v 各一行），行距固定；面板高度 = 行数 × 行距 + 上下留白。先在纸上排出哪个量在哪一行，使交叉数最少，再写坐标。
- **竖排薄层节省宽度。** 连续的标准层用竖排文字的薄层（`vertical: true`）表示，属于同一个子块的层贴边相接（Conv|GN|SiLU），不同子块之间留箭头。一个横向面板里薄层取同一高度。
- **总览用图形编码代替文字。** 块的高度表示分辨率，块内的色条表示组成，下方对齐的表格给出通道数和分辨率。相同分辨率的块合并为一个刻度。

## 颜色与图例

颜色表示块的类型，并在所有层保持一致：总览里的一条蓝色色条、阶段列里的蓝色节点、算子面板的蓝色边框是同一个东西。读者靠颜色在三层之间对应，不靠引线。

- 面板取所展开块的色调，底色比块本身浅一级（`panel` 默认如此）；面板内的标准层用白底，只有需要强调的算子用该色调。
- 标准层不着色。整张图通常三到四种色调：论文的贡献一种，主要的现成块一种，条件通路一种，其余为中性色。
- 条件通路（时间嵌入等）用独立的色调和虚线，与数据流区分。
- 运算符圆圈、色块、线型都进图例。图例放在总览的标题行，不单独占一块面积。

## 连线

- **用名字代替长线。** 一个量在别处再次使用时（跳连、锚点、时间嵌入），在使用处写它的符号，不从源头拉线过去。只有总览层的跳连值得画成弧线，因为它们就是这张图要展示的结构。
- **广播到多处的量画成一条母线加短支线**（时间嵌入到每个阶段），不画成多条平行长线。
- **嵌套的弧线从内到外排列**，利用块的高度差让弧线互不交叉。
- **交叉先靠重排行序消除。** 确实无法消除时，用 `hop` 让后画的线跨过先画的线，并把跨越点放在一段平直的线上，远离箭头和分支点。一个面板内的跨越不超过一两处。
- **分支点画圆点**，汇合用运算符圆圈。线上的信号名用斜体数学符号，放在线的上方或起点附近。

## 放大引线

`zoom` 从被展开的块连到它的面板，是淡色的梯形，位于最底层且不参与审计。因此需要人工确认：引线不压任何文字，不被别的面板截断，两条引线不交叉。总览到阶段列通常不画引线——用编号和颜色对应即可（总览图例写“ResBlock (c)”，面板标题写“(c) ResBlock”）。

范例图中有一条引线穿过了另一个面板下方的说明文字，这是应当避免的做法：调整列的位置，让每条引线只经过空白。

## 标注

- 面板标题放在面板内左上角，形如“(c) ResBlock”，用面板的色调；这样面板之间不需要为下方的说明文字留行。
- 通道变化写在层的正下方（`9→64`），用次要字号和次要颜色。
- 一个面板配一条紧凑的公式或一两行符号说明，放在空白角落，用来消除图形无法表达的歧义（例如“$\bar K$：沿空间位置取均值”）。
- 省略了什么要说明：若把权重标准化、补边等实现细节留在图外，在图注或 README 中列出。

## 自查

1. 能否只看图写出 `forward`？层的顺序、通道数、每个分支的起止是否齐全？
2. 每个特例（首级、末级、瓶颈）是否有表达，而不是被代表性的 $E_i$ 掩盖？
3. 同一类型的块在三层中是否同色？图上有没有未进图例的符号或颜色？
4. 引线是否只经过空白？是否有两条引线交叉？
5. 每个面板内的交叉是否已减到最少，剩余的是否都有跨越弧？
6. 按印刷尺寸看，薄层里的竖排文字和下标是否清晰？
